<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/PyJokeNotifier/raw/main/assets/icons/funny.ico" width="35"/> PyJokeNotifier</h1>

<p align="center">
  PyJokeNotifier é uma ferramenta leve em Python que envia piadas aleatórias por meio de notificações na área de trabalho em intervalos regulares.
</p>

## <img src="https://github.com/KrishBharadwaj5678/PyJokeNotifier/raw/main/assets/readme/fetures.gif" width="35"/> Recursos

| Recurso                        | Descrição                                                |
| ------------------------------ | -------------------------------------------------------- |
| 🎭 Notificações de Piadas      | Receba piadas aleatórias diretamente na área de trabalho |
| ⏳ Intervalo Personalizado      | Defina seu próprio intervalo entre as piadas             |
| 📢 Alertas na Área de Trabalho | Utiliza as notificações do sistema                       |
| 🔗 Integração com API          | Obtém piadas por meio de uma API online                  |
| 🚀 Leve                        | Script Python simples e rápido                           |

## <img src="https://github.com/KrishBharadwaj5678/PyJokeNotifier/raw/main/assets/readme/gettingStarted.gif" width="35"/> Primeiros Passos

### 1️⃣ Clonar o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/PyJokeNotifier.git
```

### 2️⃣ Acessar o Diretório do Projeto

```bash
cd PyJokeNotifier
```

### 3️⃣ Instalar as Dependências

```bash
pip install -r requirements.txt
```

### 4️⃣ Executar o Script

```bash
python app.py
```
