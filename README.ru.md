<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/PyJokeNotifier/raw/main/assets/icons/funny.ico" width="35"/> PyJokeNotifier</h1>

<p align="center">
  PyJokeNotifier это лёгкая утилита на Python, которая регулярно отправляет случайные шутки в виде уведомлений на рабочий стол.
</p>

## <img src="https://github.com/KrishBharadwaj5678/PyJokeNotifier/raw/main/assets/readme/fetures.gif" width="35"/> Возможности

| Возможность              | Описание                                          |
| ------------------------ | ------------------------------------------------- |
| 🎭 Уведомления с шутками | Получайте случайные шутки прямо на рабочий стол   |
| ⏳ Настраиваемая задержка | Устанавливайте собственный интервал между шутками |
| 📢 Системные уведомления | Использует стандартные уведомления рабочего стола |
| 🔗 Интеграция с API      | Получает шутки через онлайн-API                   |
| 🚀 Лёгкость              | Простой и быстрый Python-скрипт                   |

## <img src="https://github.com/KrishBharadwaj5678/PyJokeNotifier/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/PyJokeNotifier.git
```

### 2️⃣ Переход в директорию проекта

```bash
cd PyJokeNotifier
```

### 3️⃣ Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4️⃣ Запуск скрипта

```bash
python app.py
```
