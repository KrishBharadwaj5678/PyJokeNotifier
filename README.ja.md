<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/PyJokeNotifier/raw/main/assets/icons/funny.ico" width="35"/> PyJokeNotifier</h1>

<p align="center">
  PyJokeNotifierは、一定間隔でランダムなジョークをデスクトップ通知として表示する、軽量なPythonユーティリティです。
</p>

## <img src="https://github.com/KrishBharadwaj5678/PyJokeNotifier/raw/main/assets/readme/fetures.gif" width="35"/> 機能

| 機能          | 説明                      |
| ----------- | ----------------------- |
| 🎭 ジョーク通知   | ランダムなジョークをデスクトップで受け取れます |
| ⏳ カスタム間隔    | ジョーク間の通知間隔を自由に設定できます    |
| 📢 デスクトップ通知 | システム通知を使用します            |
| 🔗 API連携    | オンラインAPIからジョークを取得します    |
| 🚀 軽量       | シンプルで高速なPythonスクリプトです   |

## <img src="https://github.com/KrishBharadwaj5678/PyJokeNotifier/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/PyJokeNotifier.git
```

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd PyJokeNotifier
```

### 3️⃣ 依存関係をインストール

```bash
pip install -r requirements.txt
```

### 4️⃣ スクリプトを実行

```bash
python app.py
```
